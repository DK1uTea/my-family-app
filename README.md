# Ft My Family App

Next.js frontend generated by `create-my-stack`.

## Start locally

Install dependencies if the CLI did not do so, then run:

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000. The generator creates a gitignored `.env.local` with a local API URL (`http://localhost:3001`) and a development-only CAPTCHA bypass, so the frontend can start without manual environment setup. The public component gallery works without the API. Login and data-backed pages still need an API implementing the frontend's `/core/api/v1` routes; the generated BE starter currently exposes `/api` routes and is not a drop-in implementation of that contract.

To use another API, edit `NEXT_PUBLIC_API_BASE_URL` in `.env.local` and restart the dev server. For production, configure the variables documented in `.env.example`, provide real reCAPTCHA keys, and remove `SKIP_CAPTCHA_VERIFICATION`.

Run `pnpm typecheck`, `pnpm lint`, and `pnpm build` to verify the application. See `docs/` for architecture and feature guidance.
